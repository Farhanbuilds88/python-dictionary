# Python Dictionary Practice

This repository contains a collection of Python practice assignments focused on **mastering dictionaries**.  
The exercises cover real-world scenarios such as managing student information, restaurant menus, mobile store prices, and library books.

---

## Contributions

The code in this repository demonstrates the following **dictionary operations and concepts**:

- **Creating dictionaries**: initializing dictionaries with key-value pairs  
- **Accessing elements**: retrieving values using keys  
- **Adding items**: inserting new key-value pairs into a dictionary  
- **Updating items**: modifying existing values  
- **Removing items**: using `pop()` and `popitem()`  
- **Clearing dictionaries**: removing all elements  
- **Looping through dictionaries**: iterating over keys, values, and key-value pairs  
- **Conditional operations**: filtering items based on conditions  
- **Dictionary calculations**: summing values, finding average, and identifying maximum values  
- **Checking for keys**: using `in` to verify the presence of a key  
- **User interaction**: taking input from the user and performing dictionary lookups  

## Highlights

- Comprehensive coverage of **all fundamental dictionary operations**  
- Demonstrates **updating, deleting, filtering, and calculations with dictionaries**  
- Includes examples of **user input and search within dictionaries**  
- Provides a structured practice approach to **master Python dictionaries**
